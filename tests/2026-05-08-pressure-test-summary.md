## 5. 关键现象

| 主题 | 现象 | 结论 |
| --- | --- | --- |
| `qwen-flash` 稳定性 | 三轮非流式高并发 + 一轮流式高并发均无失败 | 当前可认为具备较强并发承载能力 |
| `mimo-v2.5-pro` 非流式表现 | 随并发提高，`HTTP 200 + content 为空` 次数持续增加 | 不适合直接按普通非流式短回复模型压测 |
| `mimo-v2.5-pro` 流式表现 | 失败数降为 0，但出现“仅返回推理过程，未返回最终答案” | 更接近其真实 reasoning 行为，但仍缺少最终答案落地 |
| 流式 Token 统计 | `qwen-flash` 该轮 usage 未被 SSE 尾包携带/采集 | 流式稳定性可判断，流式成本统计需额外补强 |

1. 优先修复 `mimo-v2.5-pro` 的兼容策略：
   - 非流式 `content` 为空时的兜底策略

2. 补强流式 usage 统计，避免 `qwen-flash` 这类 SSE 响应成本丢失。
3. 在修复后，再做一轮同级别并发回归压测，验证：
   - `mimo-v2.5-pro` 的 `empty` / “仅返回推理过程，未返回最终答案” 是否下降
   - Token 统计是否完整
